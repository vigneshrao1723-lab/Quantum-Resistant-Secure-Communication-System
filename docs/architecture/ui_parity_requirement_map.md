# Desktop / Website UI parity, chat media and the final manual-test cycle — requirement map

The Website's chat is the reference; the Desktop is brought to parity while keeping its own identity, the security model and every
working feature. Each requirement below names what changed, where, and the tests that prove it. "Owner evidence" is the screenshot
the requirement came from (18 screenshots, 2026-10-21, kept by the owner; not copied into the repository).

Status words are used strictly: **implemented and tested**, or **implemented, not independently verifiable** (with why). Nothing here
claims manual acceptance or physical-device testing — neither has happened.

## Not changed, on purpose

* The cryptography, key management, signature rules, TLS and the database roles. Everything above rides the existing pipelines.
* Android sources and build configuration (additive wire fields are ignored by the Android client; not validated on hardware).
* `master`, `main` and the preservation branch.
